# Java Lab Record

A consolidated repository containing the full Git history from four separate Java lab repositories, each preserved in its own subfolder with all original commit dates, authors, and messages intact.

---

## Repository Structure

| Folder | Description |
|--------|-------------|
| [`JavaPrograms/`](./JavaPrograms/) | Introductory Java programs covering real-world calculators and converters (age, distance, electricity bill, grocery bill, restaurant bill, salary, simple interest, temperature, travel cost, mobile data usage). |
| [`CO3-4/`](./CO3-4/) | Java programs for Course Outcomes 3 & 4 — covers OOP concepts including inheritance, interfaces, polymorphism, exception handling, serialization, and design patterns (chain of responsibility). Includes packages for geometry, HR, and payment systems. |
| [`CA2/`](./CA2/) | Continuous Assessment 2 programs — covers arrays, loops, patterns, conditional logic, and class-based design (attendance calculator, class result processor, electricity bill, movie ticket, number pattern, staff/vehicle/visitor demos, warehouse inventory, unit price calculator). |
| [`Labcycle1/`](./Labcycle1/) | Lab Cycle 1 programs — foundational Java programs demonstrating primitive data types, employee salary calculation, and finding the maximum element. |
